## Маски

Общие правила — `kit.md`, шаги 5–6. X, Y, Z — положение текселя в координатах объекта (у секции — после масштаба, S = 79 / 70); канавка — «полуширина / глубина / плато» в мм.

VentilationBox:
- Тёмный фон за ламелями: зона white на лицевой плоскости корпуса (|Y + 179| < 0,3), в проёме (|X| < 163,5 и |Z| < 79) → материал dark 001 и добавочная полость 0,6.
- Шов передней крышки: зона white (кроме тёмного фона), линия вокруг корпуса на y = −166 (13 мм от лица) — 1,2 / 0,8 / 0,3.

FanUnit:
- Шов корпуса: зона white, на y = −70 — 1,2 / 0,8 / 0,3.
- Лопасти на чаше: зона graphite, где 31,5 < Rf < 98,5 мм (Rf = √(X² + Z²)) и Y > −74,5 (чаша, без торца ступицы). Af = atan2(Z; X); t = дробная_часть((Af + 9 · Rf[м]) / (2π/5)) — пять лопастей, закрученных на 9 рад на метр радиуса. blade = smoothstep(0; 0,07; t) × (1 − smoothstep(0,62; 0,70; t)). Высота = −0,9 мм × (1 − blade): промежутки между лопастями утоплены, лопасти занимают около 62 % шага.

DuctElbow:
- Оранжевые прокладки — только цвет, без геометрии → orange 101: на трубе у нижнего фланца (√(X² + Y²) < 80,5 и 10,3 < Z < 21) и у бокового (√(Y² + (Z − 176,8)²) < 80,5 и 137 < X < 147,7).
- Линия края прокладки: у нижнего фланца (√(X² + Y²) < 80,5 и 10,3 < Z < 30) на z = 21,5 — 0,8 / 0,4 / 0; у бокового (√(Y² + (Z − 176,8)²) < 80,5 и 128 < X < 147,7) на x = 136,5 — 0,8 / 0,4 / 0.

DuctDamper:
- Тёмная внутренность трубы: зона aluminium, где √(Y² + Z²) < 64,5 · S → добавочная полость 0,45.
- Фальцевый шов снизу вдоль трубы: зона aluminium на наружной стенке (69,5 · S < √(Y² + Z²) < 70,5 · S), только Z < 0, линия y = 0 — 1,0 / 0,4 / 0.

Карта материалов: white → paint 100, aluminium → metal 010, graphite → dark 001, orange → orange 101; плюс тёмный фон короба → 001 и прокладки колена → 101. Пластика, резины, линз и ленты в наборе нет.

Полость = max(общая полость; добавочная полость).

## Подводные камни

- Масштаб секции 1,1286 — ко всей детали сразу (точки и UV); маски секции считаются с этим множителем.
- Шов полосы трубы секции лежит внизу (a0 = 180°), там же фальцевая канавка — канавка считается по 3D, поэтому шов развёртки её не рвёт.
- Тёмный фон за ламелями — только в карте материалов и полости: геометрии под ламелями нет, лицо короба сплошное.
- Прокладки колена нарисованы, а не построены.
- Общие для конвейера: круглые пятна износа у рёбер, уходящих в поверхность (болты фланцев, бобышки вентилятора, прутья у обода), и светлая грязь — см. «Подводные камни» в `kit.md`.
