## Description

You wake up on the bridge of a ship that is falling into a black hole. Space is bent so badly that a door
no longer leads to the next room. It leads wherever the things in your pocket decide — and until you step
through, the door itself does not know.

You have four pocket slots and a notebook. The notes in it were left by other versions of you, and they never lie.
Read them, choose what to carry and what to leave behind, find the combination that opens a door to the engine
room, restart the engines — and then find your way back to the bridge.

Carry the wrong things and the door opens somewhere bad: a room stuck in a looping discharge, a room where
gravity fails, a room with something that used to be a maintenance robot. Or a room with another you in it.
That one will follow you.

Every run is generated from a seed: which items matter, which are junk, what the notes say.

## Controls

| Key | Action |
|---|---|
| WASD, mouse | Move, look |
| E | Take an item, read a note |
| 1–4 | Drop the item from that pocket slot |
| Tab | Open the notebook |
| Left mouse button or F | Hit with the wrench (if you carry it) |
| Esc | Pause |

## Theme: Director's Cut

This is the version of the game I had wanted to make for a long time, without cutting the strange part:
a ship where you never choose a door, only what you bring to it.

## How it was made

Made in Unreal Engine 5.8 by one person during the jam, with heavy use of AI tools:

- Claude Code — design discussion, all game code, editor automation;
- Tripo — 3D models;
- Nano Banana — reference pictures;
- Blender — model cleanup.

The full conversation with the coding assistant is published in the repository as a development log.
