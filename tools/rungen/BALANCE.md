# Подбор баланса генератора забега

Файл пишет `python3 balance.py`. Не править руками.

Правила: комнату определяет только набор в кармане; правильный путь безопасен, аномалию несёт любое неправильное сочетание предметов. Игрок по запискам проходит за 5 дверей без урона, поэтому подбирается одно — как часто выигрывает умный перебор без записок.

Цели: по запискам не меньше 99.5% побед, умный перебор 3–4%, наугад не больше 1%.
