# tools/studio: Студия ассетов

Каталог ассетов игры поверх папок. Базы нет: папка с файлом `asset.yml` — это ассет,
а этап вычисляется по тому, какие файлы в ней лежат.

```
cd tools/studio
npm install        # один раз
npm run studio     # http://127.0.0.1:7320, откроется в браузере
npm test           # тесты сервера
```

Ассеты лежат в `SourceArt/` в корне репозитория. Другая папка — через переменную `STUDIO_ROOT`.

## Папка ассета

```
SourceArt/items/flashlight/
  asset.yml                    название, вид, идея, промт, утверждённая картинка, заметки
  images/flashlight-1.webp     картинки-кандидаты
  source/tripo/…               меш Tripo
  source/flashlight.blend
  SM_Flashlight.fbx            готовое для Unreal
  T_Flashlight_BaseColor.png
  preview.png                  необязательная миниатюра
```

```yaml
title: Flashlight
kind: model          # model или texture
style: interior      # необязательно: стиль промта, если не подходит стиль папки
idea: Chunky industrial flashlight, rubber grip, scuffed yellow body.
prompt: Chunky industrial flashlight, rubber grip, scuffed yellow body.
avoid: light beam, lit bulb   # необязательно: свои запреты, дописываются к Avoid стиля
image: flashlight-2.webp   # утверждённая картинка из images/
notes: Длина 22 см.
later: true          # отложен: карточка тускнеет и уходит из «Мой ход»
priority: 1          # необязательно: очередь работы 1–3. Карточка красится (оранжевая, бирюзовая, серая),
                     # сверху есть фильтры П1, П2, П3
generated: true      # галочка «сгенерирован»: картинка или звук сделаны у автора и в карточку не занесены.
                     # Шаг генерации закрыт без файла, карточка зеленеет и уходит из «Мой ход»
```

## Звук

Вид `sound`: идея → промт → дубли → готовый файл. Промт копируется в ElevenLabs как есть (стиль `sound`
в `studio.yml`, папка `audio`), длительность и петля выставляются там руками по полям карточки.

```
SourceArt/audio/doors/door-open/
  asset.yml                    kind: sound, prompt, seconds, loop, take
  takes/door-open-1.mp3        скачанные дубли: перетащить в карточку или взять из Загрузок
  S_DoorOpen.wav               готовое для Unreal: кнопка «В игру» у дубля (afconvert, 48 кГц, 16 бит)
```

```yaml
kind: sound
prompt: A heavy sci-fi airlock door sliding open...
seconds: 1.5         # длительность для ElevenLabs
loop: true           # необязательно: бесшовная петля (Loop в ElevenLabs)
take: door-open-2.mp3   # какой дубль сейчас в игре; ставит кнопка «В игру»
```

### Проигрыватель

- На карточке звука вместо картинки показана волна, поверх неё кнопка ▶. Играет готовый `S_*.wav`, если его нет — выбранный дубль, иначе самый свежий. На плашке указана длительность.
- В карточке ассета у каждого дубля, у готового WAV и у звуков из Загрузок есть ▶ и волна. Щелчок по волне играет с этого места.
- Снизу окна — полоса проигрывателя. На ней ⏮ ⏭ (по звукам на экране или по дублям открытого ассета), перемотка по волне, «петля», громкость и ✕. Пробел — пауза, если курсор не в поле ввода.
- Одновременно играет только один звук. Звук идёт через Web Audio, поэтому петля крутится без паузы на стыке и по ней слышно, бесшовная ли она. «Петля» включается сама у ассетов с `loop: true`.
- Волну строит сервер через `afconvert` (macOS) и запоминает до перезапуска.

Файл можно править руками или из Студии: комментарии и порядок полей сохраняются.

## Этапы

| Этап | Чем определяется |
|---|---|
| Идея | есть `asset.yml` |
| Промт | заполнено поле `prompt` |
| Картинка | поле `image` указывает на файл в `images/` |
| Tripo (только модель) | есть файл в `source/tripo/` |
| Blender (только модель) | есть `source/*.blend` |
| Готово | модель: `SM_*.fbx`; текстура: `T_*.png` |

Ассет стоит на самом дальнем этапе, для которого есть файлы. Шаги до него без файлов считаются пропущенными.
Если blend новее FBX, карточка показывает замечание «выгрузка устарела».

## Настройки и стили промта

`SourceArt/studio.yml`: папка Загрузок, путь к Blender и стили промта.

Стиль — это общий текст вокруг описания предмета. У каждого стиля свой шаблон для моделей и для текстур,
`{prompt}` в нём заменяется на описание из `asset.yml`, `{avoid}` — на свои запреты ассета. Сейчас стилей два:

- `interior` — интерьер корабля. Палитра из пяти цветов задана жёстко.
- `prop` — предметы и всё остальное. Палитры нет, цвета задаёт само описание.

Ассет получает стиль по папке (раздел `folders`, побеждает самая длинная подходящая папка), иначе `default_style`.
В карточке ассета стиль можно выбрать вручную: он запишется в поле `style` файла `asset.yml`.
Новый стиль — новый раздел в `styles`, код менять не нужно.

## Что делает Студия с файлами

- Картинку или меш из Загрузок переносит в папку ассета. Картинка получает имя `<id>-<номер>` и настоящее расширение.
- ZIP с мешем распаковывает в `source/tripo/`.
- «В Корзину» переносит файл в Корзину macOS, а не удаляет.
- «Сделать текстурой» сохраняет утверждённую картинку как `T_<Имя>_BaseColor.png`. Готовый файл перезаписывает только после подтверждения.
- Сервер слушает только `127.0.0.1` и не выходит за пределы папки ассетов и Загрузок.
